## 二、AI 企业为什么需要「可信链接层」

AI 行业正在同时面对三张考卷，而这三张考卷都不是单靠模型能力能答的：

### 1. 合规考卷
AI 生成内容标识、深度合成备案、训练数据来源说明正在成为硬性要求。企业需要的不只是「我合规」，而是**可被监管随时抽查验证的合规证据链**。

### 2. 资产考卷
AI 形象、数字人、模型权重、LoRA、训练数据集，正在变成真实可交易的资产。但这些资产**没有天然的权属凭证**——一旦被搬运、被二次商用、被冒充授权，举证成本极高。

### 3. 结算考卷
算力、Token、额度、分账，涉及模型方、算力方、平台方、创作者多方。一旦出现纠纷，"谁用了多少、该分给谁多少"往往只能靠单方后台数据说话，缺少**多方共同认可的账本**。

**链接精灵解决的正是这三件事：把「我说我合规 / 我说这是我的 / 我说该分这么多」变成「链上可查，多方共识」。**

## 四、技术架构：六层，对客只暴露最上面一层

```
产品层    链接精灵 API / SDK / 控制台 / 区块链浏览器
  ↓
接入层    多租户鉴权（productId 命名空间 + 独立 Key + 配额 + 审计）
  ↓
能力层    身份 / 形象 / 数据 / 模型 / 协作 / 金融 / 算力 / 溯源 / 治理
  ↓
合约层    AIAccountFactory · KYCRegistry · LinkSpriteNFT
          AuthorizationRegistry · Paymaster · SpriteComputeToken · TransferPolicy
  ↓
链层      FISCO BCOS 3.7 联盟链（TLS + ECDSA）
  ↓
查询层    区块链浏览器（区块 / 交易 / 地址 / Token / 授权）
```

**对客户而言，只需对接第一层。** 链、合约、节点运维、索引同步全部由我们承担。

### 多租户设计（企业最关心的隔离问题）

- 每个接入企业拥有**独立的 productId 命名空间**，Token、授权记录等资产号段不会与其他企业冲突
- 每个企业分配**独立 API Key**，配置独立权限范围、QPS 上限、日调用配额
- 所有接口调用**全量记录审计日志**，可按企业维度导出
- 密钥仅以 SHA-256 哈希形式落盘，不存储明文

## 九、合作前必须明确的四件事

我们坚持在签约前把边界讲清楚，避免后期争议：

### 1. 链上数据不可物理删除

区块链的核心特性是**不可篡改**。数据一旦上链，只能通过「标记失效 / 授权撤回」的方式处理，**无法物理删除**。

因此我们强烈建议：**上链只存哈希、凭证、索引与状态，不存原始敏感数据**。原始内容仍保存在客户自己的存储中。这是行业标准做法，也是合规前提。

### 2. 合规主体责任在企业

链接精灵提供的是**存证、追溯与验证能力**，不做内容审核背书。AI 生成内容的合规主体责任仍由内容生产/发布方承担，我们提供的是「可证明合规」的工具，不是「替客户合规」的承诺。

### 3. 密钥安全责任划分

API Key 由客户自行保管。因客户侧密钥泄露、前端硬编码、配额盗刷造成的损失，责任由客户承担。我们提供 Key 轮换、IP 白名单、配额告警等辅助手段。

### 4. 数据归属与终止处理

- 客户业务数据的**所有权归客户**
- 合同终止后，我们提供数据导出（链上记录可永久查询，链下数据按约定保留期处理）
- 已上链的存证记录因不可篡改特性将永久存在，这是服务特性而非违约
